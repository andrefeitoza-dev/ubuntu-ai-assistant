# Ubuntu AI Assistant v2.0.2

Hotfix de portabilidade e roteamento local.

## Correções

- consultas de IP usam a rota local e não são enviadas ao Ollama;
- lançadores Debian não usam mais `python -c`;
- entry points não contêm caminhos temporários do build;
- atualizações removem runtimes obsoletos sem tocar nos dados do usuário;
- auditoria do pacote valida lançadores e shebangs.

## Instalação

`sudo apt install ./ubuntu-ai-assistant_2.0.2_amd64.deb`

A atualização preserva configurações e histórico do usuário.

## Compatibilidade

Ubuntu 22.04 ou 24.04, arquitetura amd64 e Ollama externo.
