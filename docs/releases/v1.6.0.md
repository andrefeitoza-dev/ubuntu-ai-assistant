# Ubuntu AI Assistant v1.6.0

Data: 2026-08-21

## Destaques

- instalação, atualização e desinstalação controladas;
- preservação de configurações, dados e histórico;
- configurações portáteis sem exportação de segredos;
- perfis restritivos para agentes especializados;
- catálogo local de plugins com aprovação explícita;
- revogação automática da confiança após alteração do plugin;
- integração opcional e segura com VS Code;
- documentação pública de instalação, uso e solução de problemas;
- controles SSH agrupados em menu expansível;
- destino local ou remoto permanentemente visível;
- pipeline automatizado de qualidade, testes, arquitetura e build;
- auditoria de wheel e source archive;
- checksums SHA-256 verificáveis;
- atestado de proveniência sem chave privada persistida.

## Segurança

- plugins inválidos ou não aprovados não são carregados;
- configurações portáteis não incluem campos secretos ou caminhos privados;
- integração VS Code não utiliza shell nem executa ações confirmadas;
- destino remoto permanece explícito na GUI;
- artefatos com backups, bytecode, caminhos inseguros ou versões divergentes são recusados;
- assinatura de proveniência utiliza identidade efêmera do GitHub Actions;
- nenhuma chave privada de assinatura é armazenada no repositório.

## Validação

- instalação, atualização e remoção executadas em ambiente isolado;
- dados do usuário preservados durante todo o ciclo de vida;
- wheel e source archive auditados;
- checksums gerados e verificados;
- documentação construída em modo estrito;
- suíte completa, Ruff e arquitetura aprovados.
