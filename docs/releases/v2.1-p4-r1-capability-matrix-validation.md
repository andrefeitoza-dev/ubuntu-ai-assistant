# V2.1-P4-R1 — Matriz de homologação funcional

## Objetivo

Converter os recursos anunciados pela interface em casos rastreáveis de teste,
sem considerar que a presença no catálogo comprova a funcionalidade.

## Inventário

- 20 tópicos;
- 39 perguntas anunciadas;
- 8 cenários negativos complementares;
- 47 casos previstos para a homologação;
- metadados de risco, confirmação e disponibilidade preservados.

## Automação

O script `capability_matrix.py` valida o catálogo e impede divergências entre o
código e a matriz documental. CI e Release executam essa verificação.

## Estado

Todos os casos funcionais iniciam como `PENDENTE`. A aprovação ocorrerá somente
após execução real pela GUI e registro da evidência correspondente.
