# Ubuntu AI Assistant v1.6 — Validação do pipeline de release

Data: 2026-08-21

## Escopo

- CI para branches de desenvolvimento e pull requests;
- Ruff, testes, cobertura, arquitetura e documentação;
- build reproduzível de wheel e source archive;
- auditoria de nomes, conteúdo, versão e caminhos dos artefatos;
- geração e verificação de `SHA256SUMS`;
- instalação, atualização e desinstalação em ambiente isolado;
- atestado de proveniência por OIDC, sem chave persistida;
- publicação condicionada a tag compatível com a versão do pacote.

## Segurança

O pipeline não contém chaves privadas. A assinatura de proveniência utiliza a
identidade efêmera do GitHub Actions. Artefatos modificados após a geração dos
checksums são recusados.

## Interface remota

Os controles SSH foram agrupados em um menu expansível. O destino selecionado
continua visível mesmo com o menu recolhido, preservando a proteção contra
execução acidental no computador errado.
