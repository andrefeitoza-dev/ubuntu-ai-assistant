# Ubuntu AI Assistant v2.3.2

Atualização de voz, navegadores e operações reais com arquivos.

## Novidades e correções

- opção **Ouvir respostas** com síntese de voz local e desligada por padrão;
- “abra o navegador” inicia o navegador padrão configurado no Ubuntu;
- navegadores instalados podem ser abertos pelo nome, como Firefox ou Opera;
- “crie um arquivo t01 dentro da pasta Andre07” gera um plano real e verificável;
- o assistente não informa mais que criou esse arquivo quando nenhum comando foi executado.

O áudio de saída usa o `speech-dispatcher` local. Nenhum texto é enviado para serviços
externos. Ações com arquivos continuam restritas à pasta pessoal, sem sobrescrita e
protegidas por prévia e confirmação.

## Instalação

Baixe `ubuntu-ai-assistant_2.3.2_amd64.deb` e abra com dois cliques ou execute:

```bash
sudo apt install ./ubuntu-ai-assistant_2.3.2_amd64.deb
```
