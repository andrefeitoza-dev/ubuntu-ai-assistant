# Ubuntu AI Assistant v2.3.5

Atualização visual dos controles de voz.

## Alterações

- **voice input** tornou-se um círculo azul com microfone;
- **voice output** tornou-se um círculo com alto-falante;
- o alto-falante fica neutro quando desligado e verde quando ligado;
- os nomes aparecem ao passar o mouse;
- ambos continuam acessíveis por foco, Enter e barra de espaço.

O reconhecimento local já consolidado e a síntese local de respostas foram preservados.

## Instalação

Baixe `ubuntu-ai-assistant_2.3.5_amd64.deb` e abra com dois cliques ou execute:

```bash
sudo apt install ./ubuntu-ai-assistant_2.3.5_amd64.deb
```
