# Ubuntu AI Assistant v2.3.7

Correção do comando de atualização de programas e homologação das operações de arquivos.

## Alterações

- reconhece `atualize os programas`, `atualizações`, `atualize os pacotes` e frases
  equivalentes;
- apresenta o plano antes de alterar o sistema;
- solicita a senha do administrador pela janela segura do Ubuntu (`pkexec`);
- executa `apt-get update` e `apt-get upgrade -y`, sem `dist-upgrade`;
- criação de pasta, arquivo e arquivo dentro de pasta foi testada em ambiente isolado.

O assistente respeita a política de permissões do Ubuntu: operações administrativas exigem
confirmação e autorização do usuário administrador.
