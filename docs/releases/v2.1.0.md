# Ubuntu AI Assistant v2.1.0

Release de qualidade arquitetural e homologação funcional.

## Evoluções

- zero ciclos entre pacotes de alto nível;
- GUI dividida em oito componentes;
- `gui/app.py` reduzido de 2.213 para 1.374 linhas;
- fila segura para entrega de resultados ao Tkinter;
- CI, CodeQL e proteções arquiteturais modernizados;
- consultas locais e ações anunciadas corrigidas;
- variações naturais reconhecidas por planos seguros.

## Segurança

- ações críticas continuam bloqueadas;
- ações sensíveis continuam exigindo confirmação;
- nenhuma execução usa `shell=True`;
- comandos utilizam argumentos separados e auditáveis.

## Homologação

- 44 de 47 casos aprovados;
- nenhuma falha registrada;
- H16, N07 e N08 aguardam um segundo computador SSH.

## Instalação

`sudo apt install ./ubuntu-ai-assistant_2.1.0_amd64.deb`

Compatível com Ubuntu 22.04 ou 24.04, amd64 e Ollama externo.
