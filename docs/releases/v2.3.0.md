# Ubuntu AI Assistant v2.3.0

Esta versão amplia o assistente local com configuração gráfica, comandos por voz,
diagnóstico seguro do computador e manutenção controlada do Ubuntu.

## Principais novidades

- instalador gráfico opcional para Ollama, modelo local e reconhecimento de voz;
- botão **Falar**, com reconhecimento local em português e execução direta do pedido;
- resposta segura para “Como está o computador?”;
- apresentação para “Quem é você?” e lista ampliada do que pode ser perguntado;
- planos confirmáveis para limpeza, atualização de pacotes e ativação do UFW;
- fonte maior e mais legível na interface.

## Segurança e privacidade

- áudio e transcrição permanecem locais e a transcrição não aparece na conversa;
- o diagnóstico não revela endereços, portas, processos ou dados pessoais;
- ações que modificam o sistema exibem plano, risco e botões para confirmar ou cancelar;
- comandos privilegiados são limitados a uma lista exata e usam a autenticação gráfica
  do Ubuntu.

## Instalação

Baixe o arquivo `ubuntu-ai-assistant_2.3.0_amd64.deb` e instale com dois cliques ou:

```bash
sudo apt install ./ubuntu-ai-assistant_2.3.0_amd64.deb
```

Depois, abra **Ubuntu AI Assistant** no menu de aplicativos. Se a IA local ou a voz
ainda não estiverem prontas, use **Configurar Ubuntu AI Assistant**.
