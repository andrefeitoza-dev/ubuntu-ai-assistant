Data: 2026-08-19

Assistente Ubuntu inteligente, rápido, contextual e seguro para apresentação do TCC.

## Destaques

- roteamento entre resposta local, ação segura e conversa;
- conversação geral pelo Ollama com memória recente;
- Fast Path adaptativo com sinônimos e aprendizado aprovado;
- métricas de desempenho por rota;

- ações desktop validadas para pastas, arquivos, sites e aplicativos;
