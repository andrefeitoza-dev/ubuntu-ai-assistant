# Ubuntu AI Assistant v2.3.1

Atualização corretiva da interface e das operações locais com arquivos.

## Correções

- **Computador local** agora abre em um painel abaixo da barra superior, como as
  demais abas, sem esconder seu conteúdo;
- pedidos claros para criar arquivos usam uma rota local rápida e segura;
- pedidos para remover arquivos ou pastas usam a Lixeira, permitindo recuperação;
- essas operações não dependem mais da resposta do Ollama para serem planejadas.

Todas as alterações continuam exibindo uma prévia e exigindo confirmação antes da
execução. Caminhos fora da pasta pessoal, links simbólicos, nomes inseguros e
sobrescritas permanecem bloqueados.

## Instalação

Baixe `ubuntu-ai-assistant_2.3.1_amd64.deb` e abra com dois cliques ou execute:

```bash
sudo apt install ./ubuntu-ai-assistant_2.3.1_amd64.deb
```
