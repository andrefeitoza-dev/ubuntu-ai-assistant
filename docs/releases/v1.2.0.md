# Ubuntu AI Assistant v1.2.0

Data prevista: 2026-08-16

## Destaques

- GUI moderna em Tkinter;
- launcher, ícone e integração com o Dock;
- autoexecução exclusiva para `LOW`;
- confirmação para `MEDIUM`, `HIGH` e `CRITICAL`;
- mensagens amigáveis e interrupção cooperativa;
- atalhos `Esc` e `Ctrl+L`;
- instalador incluído no wheel.

## Instalação

Use `pipx install .` e depois `ubuntu-ai-install-launcher`.

## Segurança

Riscos sensíveis permanecem aguardando confirmação explícita.

## Limitação conhecida

A interrupção descarta resultados tardios, mas não encerra à força um processamento já iniciado.

## Próxima evolução

Fast Path adaptativo, mais frases, similaridade de intenções e menor latência.
