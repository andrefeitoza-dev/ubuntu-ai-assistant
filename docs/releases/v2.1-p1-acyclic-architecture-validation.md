# V2.1-P1 — Contratos e arquitetura acíclica

## Objetivo

Eliminar o ciclo entre pacotes de alto nível sem alterar o comportamento,
as políticas de segurança ou os caminhos públicos existentes na v2.0.2.

## Alterações

- `AgentContext` e `ContextProvider` foram movidos para `context.provider`;
- `agent.context` permanece como fachada de compatibilidade;
- `ContextEngine` passou a depender de um contrato mínimo de histórico;
- a dependência `context -> agent` foi removida;
- `PlanningProfile` foi movido para `decision.models`;
- `planner.models` permanece como fachada de compatibilidade;
- a dependência `decision -> planner` foi removida;
- o verificador passou a rejeitar as duas direções proibidas;
- um teste automatizado passou a rejeitar ciclos entre pacotes de alto nível.

## Compatibilidade

Os caminhos públicos anteriores continuam válidos:

- `ubuntu_ai.agent.context.AgentContext`;
- `ubuntu_ai.agent.context.ContextProvider`;
- `ubuntu_ai.planner.models.PlanningProfile`.

Os testes confirmam que os objetos exportados pelas fachadas mantêm identidade
com as novas definições canônicas.

## Resultado

O V2.1-P1 remove a dívida arquitetural registrada desde a v1.2 e estabelece
proteção automatizada para impedir sua reintrodução.
