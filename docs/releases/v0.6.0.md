# Ubuntu AI Assistant v0.6.0

A v0.6.0 encerra a fase de fundação do Ubuntu AI e posiciona o projeto como um framework local para construção de agentes inteligentes voltados ao Linux.

## Destaques

- pipeline seguro de planejamento, preview, confirmação e execução;
- IA local por Ollama;
- memória, aprendizado, reflexão, conhecimento e RAG;
- skills, plugins e seleção inteligente de ferramentas;
- TUI com Rich;
- logging, diagnóstico e benchmark;
- SDK Python e mais de 300 testes.

## Instalação

```bash
pipx install .
ubuntu-ai doctor
ubuntu-ai tui
```

## Próxima fase

A v0.7.0 será dedicada ao Intelligent Runtime: planejamento iterativo, recuperação de falhas, múltiplos provedores e APIs públicas mais estáveis.
