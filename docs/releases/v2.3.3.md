# Ubuntu AI Assistant v2.3.3

Atualização de clareza dos controles de voz e confirmação visual de arquivos.

## Alterações

- o botão de ditado agora se chama **>> voice input**;
- o botão que lê respostas agora se chama **voice output**;
- a cor de **voice output** mostra se a leitura está ligada ou desligada;
- após criar um arquivo ou pasta, o card mostra o caminho efetivamente criado;
- se a janela Arquivos já estiver aberta, o assistente orienta pressionar `F5`.

O reconhecimento de voz consolidado foi preservado. Uma criação só é anunciada depois
que o comando real retorna sucesso; respostas da IA não podem simular essa execução.

## Instalação

Baixe `ubuntu-ai-assistant_2.3.3_amd64.deb` e abra com dois cliques ou execute:

```bash
sudo apt install ./ubuntu-ai-assistant_2.3.3_amd64.deb
```
