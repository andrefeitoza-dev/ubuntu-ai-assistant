# Ubuntu AI Assistant v2.0.1

Release de distribuição simplificada para usuários do Ubuntu.

## Instalação recomendada

Baixe `ubuntu-ai-assistant_2.0.1_amd64.deb` e abra pela Central de Aplicativos ou
execute:

```bash
sudo apt install ./ubuntu-ai-assistant_2.0.1_amd64.deb
ubuntu-ai-setup
```

O aplicativo passa a aparecer no menu do Ubuntu. Para baixar o modelo padrão:

```bash
ubuntu-ai-setup --pull-model
```

## Conteúdo do pacote

- aplicação e dependências Python isoladas em `/opt/ubuntu-ai-assistant`;
- comandos `ubuntu-ai`, `ubuntu-ai-gui` e `ubuntu-ai-setup`;
- ícone e entrada desktop instalados globalmente;
- configuração inicial verificável para Ollama e `qwen2.5:3b`;
- correções pós-v2.0.0 de instância única e respostas temporais locais.

## Compatibilidade inicial

- Ubuntu 24.04 ou compatível;
- arquitetura `amd64`;
- runtime Python 3.12 e Tkinter incorporados ao pacote;
- Ollama instalado separadamente por depender do hardware e do volume do modelo.

## Remoção

```bash
sudo apt remove ubuntu-ai-assistant
```

Configurações e histórico do usuário permanecem preservados.

## Validação de compatibilidade

O pacote portátil foi instalado e executado em um MacBook Air com Ubuntu 22.04.
O sistema possuía Python 3.10, mas o assistente utilizou corretamente o runtime
Python 3.12.13 incorporado. Ollama, modelo, ícone, comandos e interface gráfica
foram validados no equipamento independente.
