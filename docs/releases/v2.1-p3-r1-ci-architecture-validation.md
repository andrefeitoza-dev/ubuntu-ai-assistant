# V2.1-P3-R1 — CI moderno e proteção arquitetural

## Objetivo

Atualizar as actions que ainda utilizavam Node.js 20 e proteger
automaticamente a decomposição conquistada na interface gráfica.

## Actions atualizadas

- `actions/setup-python`: v5 para v7;
- `actions/upload-artifact`: v4 para v6;
- `github/codeql-action`: v3 para v4;
- `actions/attest-build-provenance`: v2 para v4;
- `softprops/action-gh-release`: v2 para v3.

`actions/checkout@v6` e `astral-sh/setup-uv@v7` já utilizavam runtimes atuais e
foram preservadas.

## Proteção arquitetural

O novo `scripts/check_gui_architecture.py`:

- limita `gui/app.py` a 1.400 linhas;
- exige a presença dos componentes extraídos;
- verifica as delegações visuais principais;
- é executado tanto no CI quanto no workflow de Release;
- possui testes automatizados próprios.

## Garantias preservadas

Continuam ativos:

- Ruff;
- Pytest e cobertura;
- auditoria arquitetural;
- documentação estrita;
- build de wheel, source archive e pacote Debian;
- auditoria e checksums dos artefatos;
- ciclo de instalação limpa;
- attestations de proveniência;
- publicação da GitHub Release.

## Evidências locais

- testes dos workflows aprovados;
- suíte completa aprovada;
- documentação estrita aprovada;
- arquitetura geral e da GUI aprovadas;
- zero ciclos entre pacotes de primeiro nível.

A validação remota será concluída após os workflows disparados pelo push.
