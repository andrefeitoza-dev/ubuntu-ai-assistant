# Ubuntu AI Assistant v2.3.4

Correção da atualização visual após criar arquivos ou pastas.

## Correção

Depois da criação confirmada, o assistente abre ou focaliza automaticamente a pasta
onde o novo item foi criado. A janela **Arquivos** passa a mostrar o conteúdo atualizado
sem depender de esperar ou pressionar `F5`.

A abertura da pasta aparece como uma segunda etapa na prévia. A criação continua
restrita à Home, sem sobrescrita e protegida por confirmação.

## Instalação

Baixe `ubuntu-ai-assistant_2.3.4_amd64.deb` e abra com dois cliques ou execute:

```bash
sudo apt install ./ubuntu-ai-assistant_2.3.4_amd64.deb
```
