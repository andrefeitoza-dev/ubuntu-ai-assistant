# V2.1-P4-R3 — Consultas locais do runtime

## Objetivo

Responder localmente consultas factuais de SSH, Docker, Python, versão e
instalação, sem Ollama, shell interpretado ou alterações no computador.

## Alterações

- criado `RuntimeStatusResponder`;
- provedores somente leitura e limitados por timeout;
- discos anunciados reconhecidos pelo planejador builtin;
- pontuação final normalizada para correspondência builtin;
- perguntas conceituais continuam seguindo para conversa.

## Segurança

- subprocessos usam argumentos fixos e `shell=False`;
- nenhum comando exige sudo;
- nenhuma instalação ou atualização é executada;
- indisponibilidade gera resposta controlada.

## Evidências

- seis casos anunciados reclassificados;
- testes específicos e suíte completa aprovados;
- arquitetura permaneceu sem ciclos.
