# Guia do usuário

## Principais comandos

```bash
ubuntu-ai doctor
ubuntu-ai health
ubuntu-ai plan "instale docker"
ubuntu-ai run --dry-run "instale docker"
ubuntu-ai run "instale docker"
ubuntu-ai lifecycle status
ubuntu-ai ecosystem profiles
```

## Fluxo

1. Descoberta de contexto.
2. Construção da intenção.
3. Planejamento.
4. Preview.
5. Confirmação.
6. Execução.
7. Reflection.
8. Aprendizado.
