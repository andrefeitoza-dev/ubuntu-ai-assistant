# M6.0.1 — AI Runtime Diagnostics

## Objetivo

Adicionar diagnóstico reproduzível para problemas de conexão, modelo, geração e
formato de resposta do provedor local de IA.

## Comando

```bash
ubuntu-ai diagnose-ai
```

Uma solicitação alternativa pode ser usada no teste estruturado:

```bash
ubuntu-ai diagnose-ai --request "mostrar o usuário atual"
```

## Verificações

- disponibilidade e versão do servidor Ollama;
- existência do modelo configurado;
- geração mínima para separar problemas do servidor de problemas do prompt;
- geração usando o contrato JSON real do Planner;
- validação do JSON e dos campos obrigatórios;
- tamanho e prévia segura do prompt;
- duração de cada chamada.

## Decisões

- O comando não executa comandos do sistema.
- Avisos de JSON não invalidam a conectividade do runtime.
- Falhas de servidor, modelo ou geração retornam código de saída 1.
- O diagnóstico usa o mesmo `AppConfig` e `OllamaService` da aplicação.
