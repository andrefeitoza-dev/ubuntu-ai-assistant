# M5.2 — Execution Intelligence

## Objetivo

Validar se cada etapa selecionada pode ser executada antes de chamar o executor.

## Componentes

- `DiscoveryEngine`: detecta executáveis, caminhos e versões com cache.
- `PreflightEngine`: valida sistema operacional, executável, dependências, versão mínima e elevação.
- `ExecutionIntelligence`: associa a etapa à capacidade e produz o relatório de preflight.
- `AgentRuntime`: bloqueia a etapa quando o preflight encontra erro impeditivo.

## Fluxo

`Planner -> ToolSelectionEngine -> ExecutionIntelligence -> ControlledExecutor`

Falhas de versão e elevação são inicialmente avisos. Ferramenta ausente, plataforma incompatível e dependência ausente são erros impeditivos.

## Compatibilidade

Os novos campos de `ToolCapability` têm valores padrão, preservando as capacidades e integrações existentes.
