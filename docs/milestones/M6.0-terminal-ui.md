# M6.0 — Terminal UI

## Objetivo

Disponibilizar uma interface interativa de terminal para operar o Agent Loop,
visualizar planos, confirmar execuções e consultar informações operacionais sem
exigir uma interface gráfica ou dependências adicionais.

## Decisões

- A primeira interface usa `Rich`, já presente nas dependências do projeto.
- Não foi adicionada dependência de `Textual` nesta milestone.
- Toda execução continua exigindo confirmação explícita.
- A TUI consome apenas fachadas públicas: `AgentLoopController`,
  `MemoryService` e `PluginRegistry`.
- Interrupções de teclado e fim de entrada encerram a aplicação com segurança.

## Comando

```bash
ubuntu-ai tui
```

## Comandos internos

- `:help`: mostra ajuda.
- `:status`: exibe o estado atual do Agent Loop.
- `:history`: lista execuções persistidas recentes.
- `:plugins`: lista plugins carregados.
- `:quit`: encerra a interface.

## Fluxo

1. O usuário informa um objetivo.
2. O Agent Loop produz uma prévia.
3. A interface solicita confirmação explícita.
4. Os resultados são exibidos em tabela.
5. Em caso de replanejamento, o novo plano é exibido e confirmado novamente.

## Critérios de aceite

- Interface iniciada por `ubuntu-ai tui`.
- Planos renderizados antes da execução.
- Confirmação humana preservada em todas as iterações.
- Resultados, histórico, plugins e estado disponíveis no terminal.
- Componentes testáveis por injeção de entrada e console.
- Suíte completa e Ruff sem regressões.
