# M4.3 — Persistent Conversation Engine

## Objetivo

Adicionar histórico conversacional persistente ao UbuntuAI, mantendo mensagens por sessão no mesmo banco SQLite utilizado pela memória de execuções.

## Arquitetura

```text
AgentRuntime
  -> ConversationEngine
  -> ContextEngine
  -> ExecutionPipeline
  -> Planner
  -> PlanningPromptBuilder
  -> AIProvider
```

## Componentes

- `ConversationMessage` e `ConversationRole` modelam mensagens.
- `ConversationRepository` define a porta de persistência.
- `SQLiteConversationRepository` mantém a tabela `conversation_messages`.
- `ConversationService` controla limites de mensagens e caracteres.
- `ConversationEngine` registra mensagens do usuário e do assistente.
- `PlanningPromptBuilder` centraliza a montagem do prompt para o planejador de IA.

## Persistência

A tabela `conversation_messages` é criada de forma idempotente em `~/.ubuntu_ai/memory.db`. O histórico de execução existente não é alterado.

## Compatibilidade

O runtime continua aceitando pipelines legados que implementam apenas `run(request)`. A integração conversacional é opcional quando o runtime é instanciado manualmente e automática por meio do `Container`.
