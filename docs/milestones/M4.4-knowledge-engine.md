# M4.4 — Knowledge Engine

## Status

Concluída.

## Objetivo

Transformar a abstração criada na M4.3.1 em uma base local de conhecimento utilizável pelo UbuntuAI.

## Entregas

- `SQLiteKnowledgeRepository` com persistência local.
- SQLite FTS5 para pesquisa textual ranqueada.
- `DocumentExtractor` para TXT, Markdown, RST, LOG, JSON, YAML e YML.
- `DocumentChunker` com sobreposição e limites naturais.
- `KnowledgeEngine` para ingestão, busca e reindexação.
- CLI `ubuntu-ai knowledge`.
- Injeção automática no `Container`.
- Recuperação de conhecimento relevante no `AIPlanner`.
- Testes unitários e de integração.

## Banco de dados

Caminho padrão:

```text
~/.ubuntu_ai/knowledge.db
```

Tabelas principais:

- `knowledge_documents`
- `knowledge_chunks`
- `knowledge_chunks_fts`

A exclusão de documentos remove seus trechos por `ON DELETE CASCADE`. Triggers mantêm o índice FTS sincronizado.

## CLI

```bash
ubuntu-ai knowledge add docs/project-context.md --tag project
ubuntu-ai knowledge list
ubuntu-ai knowledge search "arquitetura planner"
ubuntu-ai knowledge remove <document-id>
ubuntu-ai knowledge reindex
```

## Integração com o Planner

Antes de solicitar um plano ao provedor de IA, o `AIPlanner` consulta até três resultados relevantes. Os excertos são inseridos no prompt como conhecimento local, sem criar dependência direta do backend SQLite.

## Limites atuais

- Busca lexical por FTS5, ainda sem embeddings.
- Extração apenas de formatos textuais UTF-8.
- PDF e DOCX ficam para uma extensão futura do extrator.
