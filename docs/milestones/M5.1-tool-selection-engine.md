# M5.1 — Tool Selection Engine

## Objetivo

Adicionar uma camada determinística que associe cada etapa de um plano à capacidade mais adequada, sem delegar toda a decisão ao modelo de IA.

## Decisões

- `PlanStep.tool_name` é opcional para manter compatibilidade retroativa.
- A seleção ocorre depois que o plano é criado, tanto para regras quanto para IA.
- O executável real do comando tem o maior peso no ranking.
- Intenção, prioridade e histórico do Learning Engine refinam a escolha.
- `shell` é usado somente como fallback.
- O Capability Registry é separado do Tool Registry: um descreve capacidades; o outro mantém ferramentas executáveis.

## Fluxo

```text
request -> Planner -> Plan -> ToolSelectionEngine -> Plan com tool_name
```

## Capacidades padrão

- apt
- snap
- systemctl
- docker
- git
- python
- ssh
- shell

## Compatibilidade

A execução continua usando os comandos já presentes em cada `PlanStep`. A milestone apenas adiciona metadados de seleção, preparando a futura execução por ferramentas especializadas.
