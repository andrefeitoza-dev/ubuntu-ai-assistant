# M6.0.2 — AI Runtime Reliability

## Problema corrigido

O comando `ubuntu-ai plan` podia exceder o timeout mesmo quando o diagnóstico
isolado do Ollama funcionava. O fluxo real acrescenta contexto de conhecimento e
aprendizado ao prompt e, sem limite de geração, o modelo local podia continuar
gerando até ultrapassar o tempo máximo da requisição.

## Alterações

- timeout padrão ampliado de 120 para 300 segundos;
- saída do Ollama limitada a 384 tokens por geração;
- temperatura reduzida para 0.1 para planos mais determinísticos;
- modo JSON solicitado diretamente à API do Ollama;
- modelo mantido carregado por 10 minutos;
- contexto RAG limitado a 1.500 caracteres e três resultados;
- contexto de aprendizado limitado a 1.000 caracteres e três recomendações;
- spinner durante planejamento no CLI e na TUI;
- mensagens amigáveis para timeout e falhas de geração.

## Segurança

A alteração não contorna confirmação, reflexão, preflight ou políticas de
execução. Ela apenas limita e torna observável a geração do plano.
