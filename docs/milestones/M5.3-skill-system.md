# M5.3 — Skill System

## Objetivo

Transformar integrações de ferramentas em módulos registráveis, mantendo o núcleo do agente desacoplado de Apt, Docker, Git, Python, SSH e systemd.

## Componentes

- `Skill`: contrato base para capacidades, preparação e ajuda.
- `SkillRegistry`: registro, descoberta e resolução por capacidade.
- `SkillManager`: preparação das etapas antes do preflight.
- `BuiltinSkill`: implementação declarativa para integrações nativas.
- `default_skills()`: catálogo padrão da aplicação.

## Fluxo

`Planner -> ToolSelectionEngine -> SkillManager -> ExecutionIntelligence -> Executor`

O `CapabilityRegistry` agora é composto pelas skills instaladas. Uma skill adicional pode ser registrada pelo `Container.register_skill()` sem alterar o núcleo.

## Compatibilidade

Os nomes das capacidades da M5.1 e o preflight da M5.2 foram preservados. Planos existentes continuam usando `PlanStep.tool_name`.

## Critérios de aceite

- Registro e resolução de skills por capacidade.
- Rejeição de capacidades conflitantes.
- Validação de que o comando pertence à skill selecionada.
- Composição via Container.
- Suite completa sem regressões.
