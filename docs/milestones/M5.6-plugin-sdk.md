# M5.6 — Plugin SDK

## Objetivo

Disponibilizar uma API pública mínima e estável para extensões locais do Ubuntu AI,
sem expor o `AgentRuntime` ou o container interno aos plugins.

## Componentes

- `PluginManifest`: manifesto TOML ou JSON validado.
- `UbuntuAIPlugin`: contrato público para plugins.
- `PluginLoader`: importação explícita por `module:object` e validação da API.
- `PluginRegistry`: inventário de plugins ativos.
- `PluginManager`: descoberta, instalação, rollback e remoção.
- `PluginPolicy`: lista de permissões admitidas antes do carregamento.

## Manifesto

```toml
[plugin]
name = "docker-tools"
version = "1.0.0"
api_version = 1
entrypoint = "plugin:DockerToolsPlugin"
permissions = ["knowledge.read"]
```

## Segurança

A política implementada é uma barreira de admissão por capacidades. Ela rejeita
permissões não aprovadas e evita entregar objetos internos ao plugin. Ela **não é**
um sandbox de processo ou de sistema operacional. Plugins são código Python local e
devem ser instalados somente de fontes confiáveis.

## Compatibilidade

A versão pública inicial é `PLUGIN_API_VERSION = 1`. Plugins com outra versão são
recusados antes da importação.

## Integração

Skills fornecidas por plugins entram no `SkillRegistry`; capacidades derivadas são
recompostas pelo fluxo já existente do container quando a aplicação é reiniciada.
